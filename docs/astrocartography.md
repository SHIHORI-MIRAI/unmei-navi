# アストロカートグラフィー（アストロマップ）機能 記録

> このドキュメントは `/astro` 機能の設計・実装・意思決定の記録です。
> 将来の改修時に、前提と判断理由を見失わないために残しています。

## 1. 概要

出生データ（生年月日・時刻・出生地の国/地域）から、**世界地図上に10天体のライン**
（MC・IC・AC・DC）を描き、世界主要都市を「どの天体が強く働くか」で評価して、
**目的別にポジティブなランキング・スコア・星評価**を提供する機能。

- 画面: `/astro`（ホームの「🌍 アストロマップ」カード、詳細ページからも導線）
- すべてブラウザ内計算（API・外部ライブラリ不使用）。localStorage のプロフィールを使用。
- 西洋占星術レイヤー（星の配置の層）を「自分だけの運命の土地」として活かす位置づけ。

## 3. 計算の要点（専門メモ）

### 天体位置（astro-core.ts）
- Paul Schlyter "Computing planetary positions" の低精度アルゴリズム。
- 検証: 2000-01-01 12:00 UT で GMST≒280.466°、各惑星の黄経が標準天文暦と一致。
- 精度: 太陽・月・内惑星は数分角、外惑星（天王星・海王星・冥王星）は 1〜2度程度。
  → ライン表示には十分だが、外惑星ラインは誤差大きめと画面に明記。

### ライン生成（astrocartography.ts）
- **MC線 / IC線**: 子午線（経度一定）。`lon = ra - GMST`（IC は +180°）。
- **AC線 / DC線**: 昇る/沈む地点の曲線。緯度φごとに `cosH = -tanφ·tanδ`、
  `H = acos(cosH)`、`lonAC = ra - H - GMST`、`lonDC = ra + H - GMST`。
  周極（|cosH|>1）はその緯度では線が存在しない。

### 都市評価（astrocartography.ts）
- 都市と線の「近さ」は **地図上の経度差**で測る（大円距離だと高緯度で線が収束して
  評価が北欧などに偏るため。アストロカートの慣例＝オーブはマップ横方向で評価）。
- 影響度は線から二次で減衰（`(1 - dist/ORB)^2`）。ORB は約10°。
- 目的別スコア = Σ(天体重み × アングル重み × 影響度) を 0..100 に飽和マッピング。
- 目的: 総合／仕事／お金／家族／恋愛／発信／学び／挑戦。天体×アングルの重みで表現。

## 4. 入力の重要度（重要な設計判断）

| 入力 | 重要度 | 理由と対応 |
|---|---|---|
| **出生時刻** | ★★★（必須級） | 地球は1時間で15°自転。**時刻が1時間ずれると全ラインが経度約15°＝東西約1,400km移動**。精度1°(≒100km)には時刻を約4分以内で。→ 時刻入力＋スライダー＋信頼度バッジで対応 |
| **タイムゾーン（生まれた国/地域）** | ★★★ | 現地時刻→UT変換に必須。`BIRTH_LOCATIONS` の選択＋出生日基準のサマータイム込みオフセット `offsetHoursForBirth` で対応済み。出生地テキストからの推定 `guessLocationId` あり |
| **緯度・経度** | ☆（ラインには不要） | アストロカートのラインは「出生の瞬間の空を地球全体に投影したもの」で、**出生地の緯度経度はラインの位置を変えない**。関与するのはタイムゾーンのみ。月の視差（最大約1°）は表示上無視可。将来のリロケーション・ハウス／パラン等の高度技法を入れる時に別途検討 |

## 5. UI/挙動の要点

- **出生時刻コントロール**: 時刻入力＋0:00〜23:59スライダー（動かすと地図の線が連動）。
  信頼度バッジ＝**高（登録時刻）／参考・仮の時刻（変更中・未登録で指定）／時刻なし**。
  時刻未登録でもスライダー指定で「仮の時刻」として地図を解禁（警告付き）。
  時刻が全く無い場合は地図を出さず、時刻の調べ方＋時刻非依存の「星の配置」を案内。
- **世界地図**（AstroWorldMap.tsx）:
  - 正距円筒図法。`viewBox` は `0 0 360 180`（x=経度+180, y=90-緯度）。
  - 背景に大陸シルエット（淡い砂色）＋経緯線＋赤道/回帰線。
  - 天体ライン: 実線=MC/AC、点線=IC、破線=DC。天体ごとに色。凡例トグルで表示切替。
  - **ズーム/パン**: ピンチ＝拡大、拡大中は1本指ドラッグ＝移動、ホイール＝拡大、
    ＋/−/⤢ボタン（最大8倍）。`viewBox` を操作。**線・点・文字の太さはズーム率で補正**し
    見た目一定（係数 `k = view.w / W`）。
  - **レベル・オブ・ディテール**: 1×はドットのみ。拡大するほど都市名が段階表示。
    密集は自動間引き（優先度＝選択＞上位おすすめ＞主要度=データ登録順）。
    表示範囲外の都市は描画しない（軽量化）。
- **ランキング**: 目的別に都市を並べ、国旗・★評価・100点満点・主要天体の星を表示。
  都市タップで詳細（効いている天体ラインの解説＋全10天体の星評価）。
